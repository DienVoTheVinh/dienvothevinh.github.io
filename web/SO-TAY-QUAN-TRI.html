2Sửa giao diện, chữ nghĩa, màu sắc

Sửa chữ (slogan, số liệu, thông tin chuyên môn…)

  1. Mở thư mục DAY HOC/web/trang-web, chuột phải file cần sửa (vd index.html) → Open With → TextEdit.
  2. Bấm Cmd+F tìm đúng câu chữ đang hiện trên web (vd "150+"), sửa thành nội dung mới, lưu lại (Cmd+S).
  3. Nháy đúp file để xem thử trong trình duyệt. Ưng rồi thì làm bước cập nhật ở mục 4.
Quy tắc an toàn: chỉ sửa phần chữ nằm giữa các dấu >…<. Đừng xoá các thẻ <div>, <p>… Lỡ hỏng thì đừng lo — GitHub giữ lại mọi phiên bản cũ, và Claude khôi phục được.

Đổi màu thương hiệu

Mở tokens.css, mọi màu đều có chú thích tiếng Việt. Ví dụ muốn đổi màu đỏ son sang xanh: sửa dòng --accent: #B5483A; thành mã màu khác (tra "color picker" trên Google để lấy mã). Lưu — toàn bộ web đổi theo, kể cả dark mode có khu riêng bên dưới.

3Thêm / đổi ảnh

  1. Chuẩn bị ảnh JPG: ảnh chân dung đặt tên anh-thay.jpg, ảnh lớp học anh-lop.jpg (đúng tên, viết thường).
  2. Thả 2 file vào thư mục trang-web.
  3. Nháy đúp index.html kiểm tra ảnh đã hiện đúng chỗ.
  4. Tải 2 ảnh lên GitHub theo mục 4 — xong.

Muốn thêm ảnh ở vị trí mới hoàn toàn (vd thư viện ảnh lớp): việc này cần thêm code — nhờ Claude (mục 10).

4Cập nhật web lên mạng — thao tác quan trọng nhất

Mỗi khi sửa bất kỳ file nào trong trang-web, làm 5 bước sau để web ngoài mạng đổi theo:

  1. Vào github.com/DienVoTheVinh/dienvothevinh.github.io (đăng nhập GitHub).
  2. Bấm nút Add file → Upload files.
  3. Kéo thả các file vừa sửa từ thư mục trang-web vào trang (file trùng tên sẽ tự thay bản cũ).
  4. Bấm nút xanh Commit changes.
  5. Chờ 1–3 phút rồi mở dienvothevinh.github.io kiểm tra. Chưa thấy đổi thì bấm Cmd+Shift+R (tải lại bỏ qua bộ nhớ đệm).
Mẹo: không nhớ đã sửa file nào thì cứ kéo thả toàn bộ file trong trang-web lên — GitHub tự so sánh, chỉ cập nhật phần thay đổi.

5Thêm tài liệu PDF từ LaTeX

  1. Vào web, đăng nhập tài khoản thayvinh.
  2. Menu Tài liệu → nút + Soạn tài liệu (nút này HS không nhìn thấy).
  3. Dán code LaTeX vào ô soạn, hoặc bấm Chọn tệp nạp file .tex có sẵn.
  4. Đặt tiêu đề, chọn lớp được xem (Mọi lớp = tất cả HS đều thấy).
  5. Bấm ▶ Biên dịch PDF → chờ 10–30 giây → PDF hiện bên phải.
  6. Ưng thì bấm 💾 Lưu vào kho — HS thấy ngay lập tức, không cần cập nhật GitHub.

Để tiếng Việt hiển thị đúng

Đầu file .tex cần có \usepackage[utf8]{vietnam} (dùng pdflatex). Nếu file của thầy dùng font đặc biệt thì chọn engine xelatex.

Xoá tài liệu đã đăng

Hiện tại làm qua Supabase: vào Table Editor → bảng documents → xoá dòng tương ứng (web sẽ hết hiện). Nút xoá ngay trên web sẽ được bổ sung sau.

texlive.net là máy chủ miễn phí của cộng đồng LaTeX — phù hợp soạn từng tài liệu, đừng đổ hàng loạt vài chục file một lúc.

6Tạo lớp & cấp tài khoản học sinh

Tài khoản HS gồm 2 phần: tài khoản đăng nhập (tạo ở mục Authentication) và hồ sơ (họ tên, lớp, vai trò — tạo bằng SQL). Em nào đăng nhập bằng tên nào là do thầy quyết: quy ước nên dùng là tenem.lop, ví dụ nguyenvana.12a1.

Bước A — Tạo lớp (làm 1 lần cho mỗi lớp)

Vào Supabase → SQL Editor → dán và Run (đổi tên lớp tuỳ ý):

insert into classes (name) values ('12A1');

Bước B — Tạo tài khoản đăng nhập cho em HS

  1. Supabase → Authentication → Users → Add user → Create new user.
  2. Email: nguyenvana.12a1@hs.vinhmath.app (tên đăng nhập + đuôi @hs.vinhmath.app — email ảo, không cần có thật).
  3. Mật khẩu: đặt tạm (vd Toan2026@), tick Auto Confirm User → Create user.

Bước C — Gắn hồ sơ (tên thật + lớp + vai trò)

SQL Editor → dán mẫu sau, đổi 3 chỗ in hoa → Run:

insert into profiles (id, role, username, full_name, class_id)
select id, 'student', 'TEN_DANG_NHAP', 'HO TEN THAT',
       (select id from classes where name = 'TEN_LOP')
from auth.users
where email = 'TEN_DANG_NHAP@hs.vinhmath.app';

Ví dụ thực tế: 'nguyenvana.12a1', 'Nguyễn Văn A', '12A1'. Xong — em A đăng nhập được ngay bằng nguyenvana.12a1 + mật khẩu thầy cấp.

Cấp cho cả lớp 40 em mà làm tay thì oải — đây chính là lý do bước tiếp theo của dự án là trang quản trị cấp tài khoản hàng loạt (dán danh sách từ Excel, bấm 1 nút). Nhắn Claude khi thầy muốn làm.

7Phân cấp tài khoản: thầy vs học sinh

Mọi tài khoản đều có cột role trong bảng profiles, chỉ nhận 1 trong 2 giá trị:

roleQuyền
teacherToàn quyền: thấy mọi dữ liệu, soạn tài liệu, sau này là giao bài, xem điểm cả lớp
studentChỉ thấy dữ liệu của chính mình + nội dung đã xuất bản cho lớp mình

Phân quyền này được cài bên trong cơ sở dữ liệu (Row Level Security) chứ không chỉ ở giao diện — HS có giỏi máy tính đến đâu cũng không đọc được điểm bạn khác hay đề chưa công bố.

Nâng một tài khoản lên quyền thầy (vd cấp cho trợ giảng) — chạy SQL:

update profiles set role = 'teacher' where username = 'TEN_DANG_NHAP';

Hạ xuống học sinh: đổi 'teacher' thành 'student' trong câu trên.

Cẩn trọng: ai có role teacher là thấy được toàn bộ dữ liệu mọi học sinh. Chỉ cấp cho người thầy tin tưởng.

8Cấp lại mật khẩu cho học sinh

Email của HS là email ảo nên không dùng được tính năng "quên mật khẩu tự động". Cách làm: vào Supabase → Authentication → Users → tìm em đó (gõ tên vào ô tìm kiếm) → bấm dấu ⋯ cuối dòng → chọn mục đổi/đặt lại mật khẩu → đặt mật khẩu mới rồi nhắn cho em. Nếu giao diện Supabase thay đổi không tìm thấy mục này, nhắn Claude làm giúp trong 1 phút.

10Nhờ Claude làm tiếp như thế nào

Mọi nâng cấp lớn (ngân hàng đề LaTeX, thi tự chấm, QR điểm danh, dashboard, cấp tài khoản hàng loạt…) đều theo một kịch bản:

  1. Mở app Claude → chế độ Cowork → chọn thư mục DAY HOC/web.
  2. Mô tả điều muốn làm bằng tiếng Việt thường, càng cụ thể càng tốt (kèm file mẫu nếu có — vd file .tex ngân hàng đề).
  3. Claude sửa code trong máy, kiểm tra, rồi cùng thầy đưa lên GitHub/Supabase như các buổi trước.

Những gì còn lại trong lộ trình đã thống nhất: ngân hàng đề LaTeX gán ID theo chuyên đề · thi trắc nghiệm tự chấm · gán bài học video + bài tập · QR điểm danh · dashboard giám sát · trang cấp tài khoản hàng loạt · tên miền riêng (vd vinhmath.id.vn, ~60–70k/năm).
